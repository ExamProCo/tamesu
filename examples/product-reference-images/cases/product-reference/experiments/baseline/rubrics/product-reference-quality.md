# Product reference quality: rationale

The images will later serve as reference inputs for scanner experiments, so a usable image
shows one product clearly (composition), is the product we asked for (brief), and is safe to
share (no real branding). Each dimension is a single yes/no claim so a reviewer can answer
quickly and the report can say *which* claim fails most. Failures carry a reason code
instead of a numeric score; scores from a model judge are the least trustworthy thing it
can produce and would add nothing to the pass rule. The overall verdict is computed: an
image passes only if every dimension passes.
